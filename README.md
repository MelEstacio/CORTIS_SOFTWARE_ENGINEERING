## Kotlin & Backend Development

Kotlin is the primary programming language for backend development, with Ktor serving as the framework for building the application's server-side architecture.

The backend follows a RESTful API architecture, responsible for handling communication between the frontend, application logic, and PostgreSQL database.

The project uses the following libraries and technologies to structure backend operations and database communication:

- **Ktor** — Building the HTTP server, routing, and RESTful API endpoints.
- **Exposed** — Kotlin SQL framework used for database interaction, table definitions, and query management.
- **HikariCP** — JDBC connection pooling for efficient and reliable database connection management.
- **PostgreSQL** — Relational database management and data persistence.

Planned backend responsibilities include:

- Building RESTful API endpoints using Ktor
- Implementing business rules and application logic with Kotlin
- Handling HTTP requests and responses
- Managing user authentication and authorization
- Managing database operations through Exposed
- Configuring and managing database connection pools with HikariCP
- Implementing data validation and error handling
- Processing features related to products, tickets, orders, payments, and user interactions
- Structuring backend components to support maintainability, modularity, and future scalability

The intention is to develop a modular backend architecture in which different responsibilities are organized into separate components, making the system easier to maintain, test, and expand.
